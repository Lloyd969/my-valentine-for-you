VALENTINE ROMANTIC — SCRAPBOOK EDITION

Cara menjalankan di VS Code:
1. Extract ZIP.
2. VS Code -> File -> Open Folder -> pilih folder valentine-romantic.
3. Pastikan extension "Live Server" sudah terpasang.
4. Buka index.html.
5. Klik kanan pada index.html -> Open with Live Server.

Isi project:
- index.html
- assets/photo1.jpg sampai photo4.jpg
- assets/music.mp3

Catatan musik:
Browser biasanya memblokir autoplay. Klik tombol "♫" di kanan atas untuk menyalakan musik.

Catatan quote:
Bagian surat memakai kutipan pendek yang kamu berikan dan dilanjutkan dengan quote original yang terinspirasi maknanya.
